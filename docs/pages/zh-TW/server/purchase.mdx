# 從 Zeabur 購買主機

如果你沒有自己的伺服器，可以直接從 Zeabur 購買伺服器。Zeabur 與主要雲端供應商（AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent Cloud、Volcengine）合作，提供具競爭力的價格——通常比直接向供應商購買還便宜。

<Callout type="info">
  購買的主機由 Zeabur 全權代管，你不需要處理 SSH 存取、作業系統更新或基礎設施維護。
</Callout>

## 購買步驟

<Steps>

### 開啟伺服器列表

登入後，點擊左側欄的 **Servers**，或直接造訪 [https://zeabur.com/servers](https://zeabur.com/servers)。

![我的伺服器頁面](/server/purchase-servers-page.png)

### 點擊「Create」並選擇「從 Zeabur 購買伺服器」

點擊右上角的 **Create** 按鈕。在彈出的對話框中，選擇**從 Zeabur 購買伺服器**。

![建立伺服器對話框](/server/purchase-create-dialog.png)

你還會看到其他選項：

- **固定 IP 伺服器** — 透過 SSH 連接你自己具有固定公網 IP 的伺服器（參見[新增主機](./register)）。
- **[Wonder Mesh](/wonder-mesh)** — 適用於沒有固定公網 IP 的伺服器（目前為 Beta 版）。

### 選擇主機方案

你會被導向主機選擇頁面。使用篩選器縮小選項範圍：

- **Provider** — 從 AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent、Volcengine 中選擇。
- **Region** — 按洲別篩選（亞洲、中國、歐洲、北美、南美、大洋洲）。
- **CPU** — 按 vCPU 數量篩選（1–32）。
- **Memory** — 按記憶體大小篩選（2 GB–64 GB）。
- **Sort** — 按推薦、價格、CPU、RAM 或流量排序。

![選擇主機方案](/server/purchase-select-server.png)

每個主機方案會顯示供應商、城市、vCPU 數量、記憶體、儲存空間、出站流量及月費。部分方案會顯示折扣標籤，標示 Zeabur 相較供應商官方價格的常態性折扣。

### 確認並付款

點擊主機方案後進入結帳流程。付款完成後，主機將自動佈建。佈建完成後（通常幾分鐘內），主機將出現在你的**我的伺服器**列表中，並顯示 **Running** 狀態。

</Steps>

## 購買後

當主機上線後，你可以：

- **[建立專案](/zh-TW/deploy/creating-projects)** 在新主機上部署服務。
- **[管理伺服器](./operate)** — 監控資源、設定配置等。
- **[設定防火牆規則](./firewall)** — 控制進出站流量。

## 常見問題

### 購買後可以升級方案嗎？

可以，你可以在伺服器的設定頁面自助升級方案。請注意，升級為單向操作——升級後無法降級至較低方案。

### 如果伺服器不符合需求怎麼辦？

透過 **Tencent Cloud**、**Aliyun** 或 **Volcengine** 購買的伺服器，Zeabur 提供一次免費退款。第二次退款需透過[Zeabur 支援](https://zeabur.com/support)提交申請。其他供應商（AWS、GCP、Hetzner、Linode、DigitalOcean）的伺服器，可以在伺服器設定頁面點擊**申請退款**直接操作。

### 計費方式為何？

購買的主機按月固定費率計費。選擇頁面上顯示的價格即為月費。主機將自動續約，除非你手動取消。

### 如何手動續約主機？

主機預設會自動續約：系統大約每 8 小時檢查一次，並在到期日前從餘額中扣款。為確保你的權益，請開啟自動續費，並確保餘額充足或已綁定有效的支付方式。續約金額以續約當下的方案定價為準。

如需手動續約，前往 **Dashboard → Servers** 並點擊你的主機，總覽頁面的到期日旁邊就是**立即續約**按鈕。主機列表中每張主機卡片的「⋯」選單裡也有**續約**選項。

如果因餘額不足導致續約失敗，主機會被暫時關機，但在寬限期內不會被刪除。儲值（或修正付款方式）後，下一次自動檢查會完成續約並重新開機；你也可以直接點擊**立即續約**按鈕。請在收到通知後盡快續約，避免超過寬限期後主機被刪除。

### 主機過期後會保留多久？

主機到期後會先關機並保留一段寬限期供補繳，寬限期依供應商不同約為 **3～15 天**。實際的關機與刪除日期以 Zeabur 寄送的通知信與主機頁面顯示的日期為準；若本頁內容與通知信不一致，請以通知信為準。寬限期結束後，主機及其上的所有專案將被永久刪除，無法復原。

目前各供應商的寬限期如下（天數自到期日起算）：

| 供應商 | 關機 | 最後通知 | 刪除 |
| --- | --- | --- | --- |
| AWS Lightsail、GCP、Hetzner、Linode、DigitalOcean | 到期後 1 天 | 到期後 5 天 | 到期後 7 天 |
| Tencent Cloud、Aliyun、Volcengine | 到期時 | — | 到期後約 15 天 |

在寬限期內完成續約，主機即可恢復上線，資料保持完好。寬限期的天數可能隨供應商政策調整，Zeabur 保留調整寬限期機制的權利。為避免資料遺失，請務必在收到通知後盡快續約，不要等到寬限期的最後一天。

### 有哪些供應商可選？

Zeabur 目前提供 AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent Cloud 和 Volcengine 的主機，資料中心遍佈亞洲、歐洲、北美、南美和大洋洲。
