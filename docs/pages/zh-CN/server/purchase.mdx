# 从 Zeabur 购买服务器

如果你没有自己的服务器，可以直接从 Zeabur 购买服务器。Zeabur 与主要云服务商（AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent Cloud、Volcengine）合作，提供有竞争力的价格——通常比直接从服务商购买更便宜。

<Callout type="info">
  购买的服务器由 Zeabur 全权托管，你不需要处理 SSH 访问、操作系统更新或基础设施维护。
</Callout>

## 购买步骤

<Steps>

### 打开服务器列表

登录后，点击左侧栏的 **Servers**，或直接访问 [https://zeabur.com/servers](https://zeabur.com/servers)。

![我的服务器页面](/server/purchase-servers-page.png)

### 点击「Create」并选择「从 Zeabur 购买服务器」

点击右上角的 **Create** 按钮。在弹出的对话框中，选择**从 Zeabur 购买服务器**。

![创建服务器对话框](/server/purchase-create-dialog.png)

你还会看到其他选项：

- **固定 IP 服务器** — 通过 SSH 连接你自己具有固定公网 IP 的服务器（参见[注册服务器](./register)）。
- **[Wonder Mesh](/wonder-mesh)** — 适用于没有固定公网 IP 的服务器（目前为 Beta 版）。

### 选择服务器方案

你会被跳转到服务器选择页面。使用筛选器缩小选项范围：

- **Provider** — 从 AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent、Volcengine 中选择。
- **Region** — 按地区筛选（亚洲、中国、欧洲、北美、南美、大洋洲）。
- **CPU** — 按 vCPU 数量筛选（1–32）。
- **Memory** — 按内存大小筛选（2 GB–64 GB）。
- **Sort** — 按推荐、价格、CPU、RAM 或流量排序。

![选择服务器方案](/server/purchase-select-server.png)

每个服务器方案会显示供应商、城市、vCPU 数量、内存、存储空间、出站流量及月费。部分方案会显示折扣标签，标示 Zeabur 相较供应商官方价格的常态性折扣。

### 确认并付款

点击服务器方案后进入结账流程。付款完成后，服务器将自动部署。部署完成后（通常几分钟内），服务器将出现在你的**我的服务器**列表中，并显示 **Running** 状态。

</Steps>

## 购买后

当服务器上线后，你可以：

- **[创建项目](/zh-CN/deploy/creating-projects)** 在新服务器上部署服务。
- **[管理服务器](./operate)** — 监控资源、配置设置等。
- **[设置防火墙规则](./firewall)** — 控制进出站流量。

## 常见问题

### 购买后可以升级方案吗？

可以，你可以在服务器的设置页面自助升级方案。请注意，升级为单向操作——升级后无法降级至较低方案。

### 如果服务器不符合需求怎么办？

通过 **Tencent Cloud**、**Aliyun** 或 **Volcengine** 购买的服务器，Zeabur 提供一次免费退款。第二次退款需通过[Zeabur 支持](https://zeabur.com/support)提交申请。其他供应商（AWS、GCP、Hetzner、Linode、DigitalOcean）的服务器，可以在服务器设置页面点击**申请退款**直接操作。

### 计费方式是什么？

购买的服务器按月固定费率计费。选择页面上显示的价格即为月费。服务器将自动续费，除非你手动取消。

### 如何手动续约服务器？

服务器默认会自动续约：系统大约每 8 小时检查一次，并在到期日前从余额中扣款。为确保你的权益，请开启自动续费，并确保余额充足或已绑定有效的支付方式。续约金额以续约当下的方案定价为准。

如需手动续约，前往 **Dashboard → Servers** 并点击你的服务器，概览页面的到期时间旁边就是**立即续约**按钮。服务器列表中每张服务器卡片的「⋯」菜单里也有**续约**选项。

如果因余额不足导致续约失败，服务器会被暂时关机，但在宽限期内不会被删除。充值（或修正付款方式）后，下一次自动检查会完成续约并重新开机；你也可以直接点击**立即续约**按钮。请在收到通知后尽快续约，避免超过宽限期后服务器被删除。

### 服务器过期后会保留多久？

服务器到期后会先关机并保留一段宽限期供补缴，宽限期依供应商不同约为 **3～15 天**。实际的关机与删除日期以 Zeabur 发送的通知邮件与服务器页面显示的日期为准；若本页内容与通知邮件不一致，请以通知邮件为准。宽限期结束后，服务器及其上的所有项目将被永久删除，无法恢复。

目前各供应商的宽限期如下（天数自到期日起算）：

| 供应商 | 关机 | 最后通知 | 删除 |
| --- | --- | --- | --- |
| AWS Lightsail、GCP、Hetzner、Linode、DigitalOcean | 到期后 1 天 | 到期后 5 天 | 到期后 7 天 |
| Tencent Cloud、Aliyun、Volcengine | 到期时 | — | 到期后约 15 天 |

在宽限期内完成续约，服务器即可恢复上线，数据保持完好。宽限期的天数可能随供应商政策调整，Zeabur 保留调整宽限期机制的权利。为避免数据丢失，请务必在收到通知后尽快续约，不要等到宽限期的最后一天。

### 有哪些供应商可选？

Zeabur 目前提供 AWS、GCP、Hetzner、Linode、DigitalOcean、Aliyun、Tencent Cloud 和 Volcengine 的服务器，数据中心遍布亚洲、欧洲、北美、南美和大洋洲。
